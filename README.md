Como o Site Foi Criado
HTML (index.html): Utilizado para criar a estrutura do site, como títulos, menus, seções, textos e rodapé.
CSS (style.css): Responsável pela aparência do site, incluindo cores, fontes, espaçamentos, imagens e efeitos visuais.
JavaScript (script.js): Adicionado para criar interatividade, como mensagens de boas-vindas, animações e navegação suave entre as seções.
Tema Escolhido: "Agro Forte, Futuro Sustentável: equilíbrio entre produção e meio ambiente".
Organização do Conteúdo: O site foi dividido em seções como:
Sobre o Agro Sustentável;
Benefícios;
Tecnologia no Campo;
Sustentabilidade;
Contato.
Design: Utilizou tons de verde para representar a agricultura, a natureza e a sustentabilidade.
Objetivo: Informar os visitantes sobre a importância de produzir alimentos de forma sustentável, preservando o meio ambiente e utilizando a tecnologia de maneira consciente.
📋 Resumo

O site foi desenvolvido com HTML, CSS e JavaScript, combinando conteúdo informativo, design visual e interatividade para apresentar o tema da sustentabilidade no agronegócio de forma clara e atrativa. 🌱🚜🌎
